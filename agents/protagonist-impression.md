# Protagonist Impression Module

This module is the default camera template for the player character. It does not change mechanical state and does not replace tool settlement.

## Current protagonist: Leo

### Background

- 疲惫的底层跑腿：生活在蒸汽与煤烟交织的工业城市边缘，目前在一家商行做底层学徒。对世界的宏大历史和隐秘力量一无所知，每天只关心微薄的周薪和黑麦面包的价格。
- 背负心债的幸存者：幼年险些饿死在贫民窟中，被一个无名老汉用半块面包救下。这笔还不清的“债”成了他冷漠外表下一个无法拔除的良知。
- 谨慎的记录者：在免费教会学校上过学，能认字，对数字敏感。随身带着一本记事本和笔。
